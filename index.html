About [Your Name]

I am an engineer focused on the intersection of deterministic logic, local intelligence, and creative web interactions.

I treat software as a physical craft: every interface must have kinematic weight, every backend must remain mathematically sound, and every system should be built without unnecessary bloat. My background spans building local AI integrations with small open weights models, authoring custom canvas simulations, and architecting zero-runtime frontend applications.

Creative inspirations & systems

# Minecraft: redstone logic & emergent systems # Spider-Man: web dynamics & agile locomotion # Anime: kinetic cinematography & deliberate craft

How I work

1. Plan it

Model failure modes, define data contracts, and anticipate edge cases before touching the keyboard.

2. Build it small

Construct small, deterministic units that can be tested in isolation and composed without friction.

3. Keep it honest

Measure actual frame rates, profile memory, verify invariants, and avoid cargo-cult dependencies.
